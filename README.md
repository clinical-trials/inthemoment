# In the Moment Jazz Website

Static website for In the Moment, built for weddings, black-tie events, and luxury venues across New Mexico.

## GitHub Pages

Upload these files to the root of a GitHub repository:

- `index.html`
- `styles.css`
- `main.js`
- `assets/`

Then enable GitHub Pages from the repository settings and publish from the main branch root.

## Local Preview

Open `index.html` in a browser, or serve the folder with any static web server.
